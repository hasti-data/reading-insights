Reader Insights

Files:
- app.py: main Streamlit application
- styles.py: styling function imported by app.py
- requirements.txt: required Python packages

Run:
1. Extract this ZIP.
2. Open a terminal in this folder.
3. Run: pip install -r requirements.txt
4. Run: streamlit run app.py

Keep app.py and styles.py in the same folder. Run only app.py; it imports styles.py.
Upload a Goodreads or StoryGraph CSV export in the app sidebar.
